# AppDatMon Admin

Giao diện quản trị web tĩnh cho backend AppDatMon.

## Chạy

1. Khởi động backend ở thư mục `backend/`.
2. Mở trình duyệt tại `http://localhost:3000/admin`.
3. Đăng nhập bằng tài khoản seed mặc định:
   - Username: `admin`
   - Password: `123`

## Chức năng

- Dashboard tổng quan và thống kê doanh thu.
- CRUD người dùng, danh mục, sản phẩm.
- Quản lý bàn ăn, đặt bàn, đơn hàng và đánh giá.
- Upload ảnh qua endpoint hiện có.
